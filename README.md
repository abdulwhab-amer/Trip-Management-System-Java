# Trip Management System

This is a simple Java project for managing trips and bookings.

The program allows users to add and manage customers, employees, and trips. It also supports booking trips, calculating prices, and searching for information by ID.

## Main Features

- Manage customers and employees
- Add and manage trips
- Book trips and calculate prices
- Search by ID
- Display information using a console menu

## Technologies

- Java
- Object-Oriented Programming (OOP)

## Project Files

- Main.java
- Person.java
- Customer.java
- Employee.java
- Trip.java
- Booking.java

## About

I developed this project to practice Java programming and apply OOP concepts in a practical way.
